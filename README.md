useState Hook:-

whenever value of useState variable changes, react re-render the component.

Syntax-

const [listOfRestaurant, setListOfRestaurant] = useState([]);  

// value inside the useState() is default value

to update value of listOfRestaurants use setListOfRestaurant()

ex- setListOfRestaurant([]);
